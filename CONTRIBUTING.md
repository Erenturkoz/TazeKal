# Katkı ve geliştirme

1. Değişiklikleri küçük ve tek amaca yönelik tutun.
2. Gerçek ortam dosyalarını veya kullanıcı verilerini eklemeyin. Örnek dosyalarla yapılandırmayı belgeleyin.
3. Flutter değişikliklerinde `flutter analyze` ve `flutter test`; backend değişikliklerinde `npm test` çalıştırın.
4. `pubspec.lock` ve `backend/package-lock.json` dosyalarını sürüm kontrolünde tutun.
5. Derleme APK/AAB dosyaları Git'e girmez. Gerekirse sahibi GitHub Releases üzerinden ayrıca dağıtır.
6. Kimlik doğrulama değişikliklerinde başarısız giriş, oturum yenileme/iptal ve kullanıcılar arası erişim sınırlarını test edin.

Projeye lisans henüz atanmadı; sahibinin seçimi olmadan lisans eklemeyin. Yayın/push işlemleri proje sahibi tarafından yürütülür.
